# Flight Management System

MSc Computer Science coursework project using Python, SQLite and SQL.

The application provides a command-line interface for managing flights, pilots and destinations, including flight retrieval, CRUD operations, pilot assignment, pilot schedules and summary statistics.

## Running the project

Create/populate the database:

```bash
python database_setup.py
```

Run the application:

```bash
python main.py
```

## Files

- `main.py` - Flight Management System command-line application
- `database_setup.py` - database schema and sample data
- `flight_management.db` - SQLite database
